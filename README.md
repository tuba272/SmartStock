# SmartStock - Stationery Inventory Management System

A systematic inventory system to manage office stationery procurement, stock, and usage.

## Features Covered (As per requirements):
1. Records procurement, stock, and usage
2. Tracks Received, Issued, and Available quantity
3. Analyzes consumption patterns & flags excessive usage
4. Low-stock alerts to prevent stock-outs
5. Need-based replenishment suggestion
6. Wastage reduction through analytics
7. Working Dashboard Prototype (Flask)

## How to Run:
pip install -r requirements.txt
python app.py

## Tech Stack: Python Flask, HTML, CSS
